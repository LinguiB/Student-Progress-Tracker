# Student Progress Tracker — GitHub Pages PWA package

## Upload
Upload the contents of this folder to the **root** of your GitHub Pages repository.
Keep the structure exactly as shown:

- index.html
- manifest.webmanifest
- sw.js
- icons/
  - icon-192.png
  - icon-512.png
  - apple-touch-icon.png
  - favicon.png

Do not upload the ZIP itself as the website. Extract it first, then upload these files/folders.

## Install
- **Android:** Open the HTTPS GitHub Pages URL in Chrome, then use the browser menu → Install app / Add to Home screen.
- **Windows:** Open the HTTPS URL in Chrome or Edge and use the install icon/menu.
- **iPhone/iPad:** Open the HTTPS URL in Safari → Share → Add to Home Screen. iOS uses this manual flow rather than the Android install prompt.

## Important data note
The app stores records locally in the browser on each device. Installing it on another device does not transfer data. Use the app's Backup feature and restore the backup on the other device. Browser storage may also be cleared by device/browser settings.

## Scope of this package
The supplied app's existing HTML, styling, layout, navigation and JavaScript features are retained. The package adds the PWA manifest, service worker, app icons, and Apple home-screen metadata. It does not convert the website into a separately published native App Store / Google Play application.
